# MeteoApp

App Android nativa (Kotlin + Jetpack Compose) per previsioni meteo, basata su API Open-Meteo (gratuita, senza chiave API).

## Funzionalità
- Temperatura attuale con icona "puffy" 3D
- Grafico orario delle prossime 12 ore
- Radar pioggia in tempo reale (RainViewer + OpenStreetMap)

## Setup
Apri il progetto con Android Studio (Hedgehog o superiore) e lascia sincronizzare Gradle.
